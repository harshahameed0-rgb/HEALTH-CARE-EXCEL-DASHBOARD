# 🏥 Healthcare Dashboard

## 📊 Project Overview

The Healthcare Dashboard is an interactive Excel-based data visualization project designed to analyze and monitor patient information, hospital visits, treatments, diagnoses, and departmental performance.

This dashboard transforms raw healthcare data into meaningful insights through interactive charts, summary cards, and filters, helping users understand patient trends and hospital operations.

## 🎯 Objectives

- Analyze patient demographics and hospital visits.
- Identify the most common diagnoses and treatments.
- Monitor patient waiting times across departments.
- Track monthly patient visit trends.
- Analyze the average length of patient stays.
- Compare billing across different departments.
- Provide an interactive and user-friendly healthcare reporting dashboard.

## 📁 Dataset

The dataset contains patient and hospital visit information, including:

- Patient ID
- Visit ID
- Visit Date
- Age
- Gender
- Department
- Doctor
- Visit Type
- Diagnosis
- Treatment
- Admission Date
- Discharge Date
- Billing Amount
- Patient Waiting Time

## 📈 Dashboard Features

The dashboard includes the following key metrics and visualizations:

- **Total Number of Patients**
- **Average Length of Stay**
- **Emergency Visits**
- **Most Common Diagnosis**
- **Total Patient Waiting Time**
- **Most Common Treatment**
- **Patient Visits by Department**
- **Monthly Patient Visit Trends**
- **Monthly Patient Volume & Average Length of Stay**
- **Average Waiting Time by Department**
- **Total Billing by Department**

### 🎛️ Interactive Filters

Users can filter the dashboard based on:

- Gender
- Visit Type
- Doctor
- Payment Method
